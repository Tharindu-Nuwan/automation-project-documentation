What was verified for this guide

The audit reads tracked repository source at a314c7b, inspects configuration, managers, credentials/data paths, QR recipes, field setters and key integration helpers, and generates an inventory from TypeScript syntax trees. It does not import test modules or load populated .env / .auth files. Counts include opt-in tool specs as source, even when normal project collection ignores them.

No live application, login, payment, database, email or scan flow was executed. No claim here establishes current deployment availability, passing status, actual database grants, secret validity or complete conformance with external Jira/Qase test cases. Existing reports in docs/ remain historical evidence tied to their own dates/environments.

Documentation checks cover local page and section links, packaged files, offline search, and the reader interface. These checks validate the documentation bundle; they do not establish whether application tests pass. The guide was prepared without running live login, payment, database, mail, or scan actions.

How to interpret the generated references

  • Static test counts count declarations, not expanded parameter rows, browser projects, runtime passes or external test cases.
  • Import consumers are direct TypeScript imports; files read through filesystem APIs and transitive imports need manual follow-through.
  • Call lists include both sides of branches and calls inside callbacks in source order. They do not claim every call executes on every run.
  • Per-file hook lists preserve source links; enclosing describe scope determines which tests each hook applies to.
  • Long expressions are abbreviated with explicit source pointers. Dataset preview values are not a replacement for the full dataset.
  • Private methods are included because they explain retry, polling and state behavior. Source comments may describe historical environments or defects.
  • Credential-like literal values are omitted from references. Variable names, ownership, lookup sites and parameter wiring remain visible.
  • Source links open bundled HTML snapshots at line anchors. Credential-like literals are redacted; binary fixtures open metadata pages with their repository paths and measured byte sizes.

If the product or reference has changed

Record the guide page, the product and environment, the input used, and the behavior you observed. Send the mismatch to the person maintaining the tests so the expected behavior and the guide can be checked against the current source. A source snapshot explains the audited code; it is not a current test result.
