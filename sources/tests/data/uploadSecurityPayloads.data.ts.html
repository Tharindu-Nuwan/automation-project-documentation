tests/data/uploadSecurityPayloads.data.ts

Bundled source snapshot. Credential-like literals are omitted. Line numbers correspond to the audited repository file; this page is for reading and is not executable test code.

1 /**
2  * In-memory malicious/edge upload payloads for the OQG3-1996 file-upload
3  * security suite ("Prevent execution of files disguised as images").
4  *
5  * Kept as data (not inline in specs) so the same attack set is reused across
6  * every upload control and can grow in one place — same convention as
7  * `eventSecurityPayloads.data.ts`. Every payload is built in memory, so no
8  * fixture file is needed and the MIME type / extension mismatch is fully
9  * under our control (that mismatch is exactly what AC2 must catch).
10  *
11  * Ticket ACs:
12  *   AC1 — block execution of executable/script files disguised as images.
13  *   AC2 — validate the real MIME type / magic bytes match the extension.
14  */
15 
16 export interface UploadAttack {
17     /** Short, readable label used to build unique test titles. */
18     label: string
19     /** File name presented to the upload control. */
20     name: string
21     /** MIME type presented to the upload control (often a spoof). */
22     mimeType: string
23     /** Raw file bytes. */
24     buffer: Buffer
25     /**
26      * Set when this payload currently succeeds against the product, i.e. the
27      * test for it is quarantined against a documented bug id
28      * (docs/Upload_Security_OQG3-1996_Bugs.md). Never set this to silence a
29      * failure — it exists so the coverage stays visible while the bug is open.
30      */
31     knownProductBug?: string
32 }
